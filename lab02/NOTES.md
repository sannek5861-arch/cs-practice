Git - это история изменений файлов и папок на пк, а GitHub это облачное хранилище этой истории.
git diff - показывает измененные и добавленные файлы, но еще не сохраненные, git diff --staged - показывает отслеживаемые файлы
с помощью add
«Использованные команды»: git status - показывает незапомненные изменения в проекте и изменения, которые готовы к commit(у)
«Ветки»:ветка - это указатель на коммит; при новом коммите ветка переносится на новый коммит, который относится к этой ветке;
обьединяет два последних коммита с каждой ветки в один с названием главной ветки.
