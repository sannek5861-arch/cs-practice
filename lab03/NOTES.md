git log --stat показал нам каждый коммит кроме последнего

git show показал нам выбранный коммит, изменения вместе с данными того кто внес изменения

git diff показал нам только изменения выбранного коммита

git log -S"def" показал нам изменение количества упоминаний def в коде (0)

git blame показывает построчное изменения файла, кто и когда и в каком коммите последим редактировал каждую конкретную строку

git restore возвращает файл в состояние последнего коммита 

git restore --source= возвращает файл в состояние определенного коммита

git reset --hard перематывает ветку назад к указанному коммиту, а git revert отменяет изменения конкретного коммита, при этом создавая новый коммит.


тег — это указатель на конкретный коммит, а ветка это подвижная ссылка на последний коммит
